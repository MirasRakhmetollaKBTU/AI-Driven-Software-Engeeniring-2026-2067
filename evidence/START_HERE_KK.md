# Қысқаша нұсқаулық

1. final бумасында терминал аш: npm ci, содан кейін npm run dev.
2. Терминалдағы жергілікті сілтемені аш.
3. README ішіндегі Demonstration қадамдарын қайтала.
4. npm test пәрменімен 64 тесттің өтуін тексер.
5. PDF есепті оқып, AI reflection бөлімін өз түсінігіңмен тексер. Өзің жасаған шолуды human-review.md файлына жаз.
6. Терезені 375 px еніне тарылтып, мәтін мен өрістердің дұрыс көрінетінін тексер. Кейінгі браузер тексеруінде 375 px көрінісі қаралды, көлденең асып кету байқалмады.
7. Дайын ZIP ішінде initial, final, есеп, README және тест нәтижелері бар. node_modules қоспағандықтан, көлемі шағын.

Қорғауда түсіндіру:
- filterRooms: capacity >= attendees және equipment.every арқылы барлық таңдалған жабдықты талап етеді.
- selectVisibleRoom: таңдалған бөлме сүзгіден өтпесе, бірінші сәйкесті бөлмені алады; ештеңе болмаса null.
- evaluateRequest: мәтіндік уақытты тексеріп, таңдалған бөлменің bookings тізімін validateBooking функциясына береді.
- validateBooking: дұрыс аралық, болашақ уақыт, 120 минут шегі, blocked және қиылысуды тексереді.
- Қиылысу: start < existing.end && existing.start < end. Сондықтан шекаралары тиіп тұрған аралықтар рұқсат етіледі.
- Нәтиже бөлек күйде сақталмайды; ағымдағы бөлме мен уақыттан есептеледі. Осылай бөлме ауысқанда ескі нәтиже қалмайды.
